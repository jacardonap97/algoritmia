# Distribución

En este repositorio se encuentran los ejercicios del trayecto 1 de Algoritmia, en él se pueden encontrar los siguientes directorios:

## algoritmia-s1:
Aquí se encuentran los algoritmos de iniciación en Pseint, donde se aprendieron conceptos como entradas, procesos y salidas.

---

## algoritmia-s2
Acá se pueden apreciar algoritmos mejor elaborados mediante el estudio y comprensión de las tablas de verdad y condicionales.

---

## algoritmia-s3
En esta carpeta pueden observarse algoritmos un poco más complejos donde se integraron y entendieron las estructuras cíclicas.
